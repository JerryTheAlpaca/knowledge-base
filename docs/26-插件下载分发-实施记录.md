# 插件下载分发：设计与实施记录

记录日期：2026-10-04。状态：代码完成，服务端测试通过，agent-browser 走查两个入口均已渲染；
**未部署生产**。

## 1. 目标

把 Obsidian 插件放到 kb.jerrythealpaca.cn 上，让别人能直接下载安装。设两个入口：

1. 设置页「Obsidian 知识库」卡片——未连接时给出下载入口。
2. 新手指导第二步——给出下载入口。

## 2. 关键约束：产物怎么进镜像

api 镜像的 build context 是 `apps/server`（`deploy/docker-compose.yml`），拿不到
`apps/obsidian-plugin` 的源码；服务器上也没有 node，部署时无法现场跑 esbuild。
所以不能在部署流水线里构建插件。

选定方案：发布产物作为**纯文本文件**入库到 `apps/server/kbserver/plugin_dist/`，随
`COPY kbserver ./kbserver` 进镜像；服务端在请求时用 Python 的 `zipfile` 现打 zip。
不入库二进制，避免仓库里出现每次构建都变的 blob。

`plugin_dist/` 由 `apps/obsidian-plugin/scripts/sync-dist.mjs` 从插件目录同步，
package.json 加了 `npm run release`（= build + dist）一步到位。脚本校验
`manifest.id` 必须是 `golden-rose-inbox`——目录名与 id 不一致时 Obsidian 认不出来。

发布流程：改插件源码 → `npm run release` → 提交（源码 + `plugin_dist/` 三个文件）。

## 3. 端点

`apps/server/kbserver/api/routes_plugin.py`：

| 端点 | 用途 |
| --- | --- |
| `GET /downloads/golden-rose-inbox.zip` | 现打 zip。`Content-Disposition: attachment`，文件名带版本号 |

**不需登录**：安装发生在登录之前，登录是插件里的下一步。`routes_web` 里的
`/inbox` 那些页面本身要登录，插件下载不需要。

首版还有一条 `GET /v1/plugin/release` 返回版本号供界面显示，界面去掉版本号后
一并删除——留着就是没有使用方的死代码。版本信息仍在 zip 的文件名与 ETag 里。

zip 结构（`test_zip_layout_matches_obsidian_expectation` 盯着）：

```
golden-rose-inbox/manifest.json
golden-rose-inbox/main.js
golden-rose-inbox/styles.css
```

根目录这一层文件夹名必须是插件 id——用户把它解压到 `<库>/.obsidian/plugins/` 下
就能直接被认出来。少任何一个文件插件都加载不出来。

产物按 mtime 判缓存，进程内缓存 parts：重新发布后无需重启进程。
zip 内条目的时间戳固定为 2026-01-01，同样的产物打出同样的字节，浏览器/CDN 缓存才有意义。

## 4. 前端

新模块 `web_static/js/plugin-download.js`，两个入口共用同一段渲染——安装说明只写一份，
不会两处漂移：

- `pluginInstallHTML()`：下载按钮 + 三步安装说明。

按钮用 `.small`（32px 视觉高度）而不是默认的 44px 档：设置页里它与同卡片下方的
「更新登录态」等按钮并排，默认档会明显高一截。命中区靠 `.small` 的 `::after`
扩到 44px，触控基准不丢。

第三步只写「在插件设置里用同一账号登录。」——连上之后这页自己会变，安装说明里
不必预告。

接入点：

- `settings.js` 的 `loadDevices()`：`!sum.connected` 时渲染下载入口，同时隐藏底部那句
  静态 help（三步说明已覆盖，重复了）；已连接时反向。
- `js/onboarding.js` 第二步：把原来「在电脑版 Obsidian 中安装 KB Inbox 插件」这句
  换成真正的下载入口（插件已改名 Golden-Rose-Inbox，文案同步更正）。

样式 `.pd*` 加在 `inbox.css`（`.pd-steps code` 用 var(--text) 而不是继承的
--text-2，代码片段要能看清）。
