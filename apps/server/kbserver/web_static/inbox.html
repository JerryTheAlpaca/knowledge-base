长成你自己的知识

我们终日行走在生活的尘埃里。

读过的文字，偶然闪过的念头，

一次谈话，一点困惑，一瞬间的领悟——

它们散落在时间里，微小得像一粒粒金粉。

把它们拾起、筛选、积攒，

让零散的知识彼此相遇，

让模糊的思想渐渐成形。

直到有一天，

这些微小的金粉，

会成为属于你的那一朵——

金蔷薇

怎么用

  1. 拾取粘贴一条链接，或者写下此刻的念头

    不用先想清楚放哪里。公众号、小红书、B 站、视频号、知乎、网页、AI 对话，一条链接就够；文件、录音和一句话的灵感同样收。

  2. 积攒你关机的时候，服务器接着替你干活

    云端提取正文、语音转写、图像识别，再用大模型整理、提炼。

  3. 成形回到你自己的 Obsidian 库

    插件把原始材料和整理结果下载回本地，按你的目录落盘、可重试不重复建笔记；更新生成内容时保护你自己的修改。整个 Vault 始终在你电脑上。

几条底线

  • 原文永远留着AI 整理只是副本，加工失败也不会让已接收的材料消失。
  • 凭据只属于你模型 Key 加密托管在服务器上，只服务你这一份额度。
  • 本地才是家云端不上传整个知识库，入库由你电脑上的插件完成。
  • 写过的算你的机器重跑不能覆盖你自己改过的段落。

开始攒金粉
